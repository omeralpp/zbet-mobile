## Bilyoner team logo mapping

```text
htpi = home participant id
atpi = away participant id

Logo pattern:
https://content.bilyoner.com/assets/participant/{participantId}.png

PSG htpi=954
https://content.bilyoner.com/assets/participant/954.png

Aston Villa atpi=227
https://content.bilyoner.com/assets/participant/227.png
```

Bu pattern Bilyoner'in public/dokümante edilmiş resmi logo API'si değildir; mevcut
web uygulamasındaki CDN kullanımının gözlemlenmesiyle bulunmuştur. URL/path değişimine
karşı merkezi resolver + fallback kullanılmalıdır. Bu cutover'da Mobile/BFF/yerel
ABAP akışında `htpi/atpi` bulunmadığı için logo uydurulmadı; upstream participant ID
sözleşmesi ayrı SAP yazma/aktivasyon onayı gerektirir.
