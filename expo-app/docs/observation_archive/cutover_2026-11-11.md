## Platform exceptions (Client Parity)

- Back control: Android at every width; web only below 768 px, because the web
  shell's rail or sidebar is present from 768 px up.
- Desktop text step: web at 1200 px and wider only; Android has no desktop layout.
- Compact list switch: affects the phone layouts on both surfaces; the desktop
  split view and decision table have their own layouts.
- Hint wording differs per surface on purpose; the capability is the same.
- Every other change is the same shared code on both surfaces.
