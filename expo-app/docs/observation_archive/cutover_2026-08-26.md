## Implementation evidence

### Scope labelling (`NXT-OBS-129`)

`LiveSwitch` takes `liveCount` and `fixtureCount` and derives label and count
from the active state. `tabCounts.FIXTURE` was already computed beside the live
count, so no contract, query or backend field changed. With the star tab active
the switch is genuinely off and reads `Fikstür`; that is the switch's own
off-position meaning and is strictly better than the previous `Canlı`, but no
separate star label was invented.

### Jinx wording path (`NXT-OBS-132`)

`zbet-cap/srv/mobile-bff/jinx-quip.js` holds a single-adapter Gemini client,
per-mood-boundary caching, and a pure validator. A candidate is refused for
length, multiline, banned advice/prediction phrasing, a figure spelled out in
words, or any digit the model was not given; phrase rules match a
diacritic-folded copy so a line written without Turkish characters cannot slip
past them. `POST /v1/jinx/quip` sits behind `requireRead`. The service is
fail-closed: with no `BTB_JINX_LLM_API_KEY` it reports disabled and the app
keeps its deterministic repertoire.

The client re-runs the length, single-line, spelled-number and verified-number
checks before display. Wording is prefetched once per mood boundary, never per
render or refetch, never while Jinx sleeps or the app is backgrounded, and the
bubble never waits on it.

Only `kind`, `filter`, `metricDate`, `won`, `lost` and `profit` leave the BFF —
no user identity, SAP payload, raw match or odds row, or model threshold — since
a free provider tier may retain the prompt. Only the rejection reason code is
logged; never the candidate text or the key.

## Corrections found during live verification

Four real defects surfaced only because the key was exercised end to end. Each
would have shipped silently.

1. `BTB_JINX_LLM_*` was missing from the User→Process copy list in
   `zbet-cap/scripts/start-mobile-bff.ps1`; the key never reached the BFF.
2. The default model `gemini-2.0-flash-lite` no longer exists, and
   `gemini-2.5-flash-lite` answers `no longer available to new users` with HTTP
   404. `gemini-3.5-flash-lite` was verified and pinned — the auto-updating
   `-latest` alias was deliberately not chosen.
3. The first prompt was written in diacritic-free ASCII Turkish; the model
   mirrored that style and produced garbled Turkish, and it read `won`/`lost` as
   goals ("4 şutu kaçırıp 1 gol atabildim"). The prompt was rewritten in proper
   Turkish and states explicitly that these are Super decision counts.
4. The model wrote figures in words, which bypassed the digit check entirely —
   and garbled them while doing so. The `spelled-number` rule and diacritic
   folding were added in response.

A fifth correction was to the verification itself: the first APK secret scan
searched raw bytes and could not see inside the compressed JS bundle, so its
"absent" verdict was unfounded. It was noticed when `api.surklase.com`
unexpectedly did not appear, and redone over decompressed entries.
