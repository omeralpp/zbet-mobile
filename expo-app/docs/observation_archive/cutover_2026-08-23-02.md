## NXT-OBS-094 finding

Audit before writing anything found `src/components/Screen.tsx` +
`src/navigation/tab-swipe.ts` already implement everything the row asked for:
all five main tabs wired via `tabSwipe`, pure and tested direction/threshold
logic (`tab-swipe.test.ts`), edge resistance instead of wrap at the first/last
tab, local-tab-first priority (`NXT-OBS-106`), and mutual exclusion with the
edge-back gesture per screen. The row had simply never been marked resolved.

The one real gap: the gesture's release/cancel spring-back used a local
`springBack` constant and never read the device's reduced-motion preference,
unlike every other animated surface in this codebase (`CollapsibleModule`,
`ChangeEmphasis`, `LiveDot`), which already goes through the shared
`useReducedMotion` / `theme.gestureSpring` convention.

Fix: `Screen.tsx` now calls `useReducedMotion()`; with it on, both the commit
settle and the cancel settle land at `0` instantly instead of animating.
Otherwise it uses the shared `gestureSpring` (same constants the local
`springBack` duplicated). No behaviour changed for the default case.
