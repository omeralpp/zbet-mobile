# BTB Mobile Next — Cutover 2026-08-09-04

## Kapsam

`NXT-OBS-066` için standalone Notification Service ile ABAP üreticisi arasındaki
yerel, secret-free producer cutover hazırlığı.

## Tamamlananlar

- Eski PID 2988 BFF sürecinin yeni degraded-mode registry davranışını yüklemediği
  doğrulandı. Önceden onaylı Windows göreviyle kontrollü restart sonrası PID
  21460 local/public health üzerinde `deviceRegistration=configured` ve
  `notificationService=unconfigured` raporladı.
- Standalone producer endpoint’i mevcut `X-BTB-Notification-Key` sözleşmesini
  korudu. SAP SM59 uyumluluğu için yalnız HTTPS üzerinden fixed user
  `btb-notifier` + raw producer key parolası kabul eden Basic adapter eklendi.
  Runtime yine yalnız producer key SHA-256 digest’ini tutar; iki credential aynı
  istekte gelirse fail-closed `401` döner.
- Yerel ABAP kaynağında eski sabit BTP CAP URL’si kaldırıldı.
  `ZBET_NOTIFICATION_API` destination ve `/v1/notifications` yolu kullanıldı;
  `general/super/toto` türü, günlük deterministik SHA-256 idempotency anahtarı ve
  HTTP başarı durumu eklendi.
- Toto job’u gerçek producer HTTP sonucunu raporlar; yalnız istek yapılmasını
  başarı gibi yazmaz.
- Aktivasyon sırası ve secret sınırı `zbet-abap/README.md` içinde belgelendi.
