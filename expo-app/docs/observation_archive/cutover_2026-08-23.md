## Kick-off odds source and display policy

Local CDS/OData metadata and ABAP source trace the Fiori `Match Odds > Odd`
row to `zbet_cds_001x`, `type='01'`. The BFF requests that bounded entity by
match id/date and maps only the published decimal-price fields. It does not use
`zbet_cds_006-kick_off`, which is a historical similarity percentage rather
than an odd.

The source publishes `Ms1`, `MsX`, `Ms2`, `Ms15a/u`, `Ms25a/u`, `Ms35a/u`,
`Kgvar` and `Kgyok`. It does not publish `Ms1X`, `MsX2` or `Ms05u`, so those
markets receive `kickoffRate: null`; no price is inferred from another market,
stale live state or a percentage. A live odd always has display priority. A
kick-off odd remains a labelled historical reference and never changes market
availability, movement, Super selection or model inputs.
