# BTB Mobile Next — 2026-08-17 cutover closure

## Work Zone deep-link double-hash regression — RESOLVED

**Bulan:** fiziksel Xiaomi kullanımı, `btb-mobile-next-arm64-workzone-integration.apk`
(2026-08-16 gece). Better Than Bet / BTB Toto / Super Log Fiori uygulamalarını
Work Zone üzerinden açma denemeleri `Illegal new hash - cannot be parsed:
'Shell-home#btb-manage?...'` gibi hatalarla başarısız oldu; Work Zone
sitesinin kendisi doğru açılıyordu.

**Kök neden:** 2026-08-16 Work Zone migration'ı `EXPO_PUBLIC_LEGACY_LAUNCHPAD_URL`
değerini sonunda `#Shell-home` ile yapılandırdı. `src/legacy/routes.ts`
içindeki üç intent builder (`buildLegacyMatchUrl`, `buildLegacyTotoUrl`,
`buildLegacySuperLogUrl`) bu değeri doğrudan temel URL kabul edip kendi
`#btb-manage` / `#SporToto-manage` / `#SuperLog-display` fragment'ını
üzerine ekliyordu; sonuç `...#Shell-home#btb-manage?...` gibi Work Zone
shell'inin ayrıştıramadığı çift fragment'tı.

**Düzeltme (`zbet-mobile` commit `7484502`):**
- `routes.ts`: `normalizeWorkZoneBaseUrl()` (var olan fragment'ı böler) ve
  `buildWorkZoneHomeUrl()` eklendi; dört URL üreticisi de (Home + 3 intent)
  kullanıcıdan gelen temel URL'yi kullanmadan önce merkezi olarak normalize
  eder — çağrı noktalarına dağınık hash temizleme eklenmedi.
- `fiori-target.ts`: hedefsiz (`launchpad`) geri dönüş artık ham yapılandırılan
  string'i döndürmek yerine `buildWorkZoneHomeUrl()` çağırır.
- `scripts/build-pilot-apk.ps1`: yapılandırılan temel URL `#` taşıyorsa pilot
  build artık build-time'da hata verir (regresyonu build kapısında yakalar).
- `.env` (yerel, commit edilmiyor): `EXPO_PUBLIC_LEGACY_LAUNCHPAD_URL` artık
  fragment'sız temel URL.
- 14 yeni regression testi: temiz taban + her üç intent + Home için tam
  olarak tek `#`; yanlış yapılandırılmış (`#Shell-home` taşıyan) taban için
  hiçbir builder'ın çift `#` üretmediği; eski tenant host'unun hiçbir
  üretilen URL'ye sızmadığı.

**Doğrulama:**
- Mobile `npm run check`: TypeScript temiz, ESLint temiz, **194/194** test
  (180 → 194, 14 yeni test dahil).
- Yeni ARM64 pilot APK derlendi ve unzip edilerek incelendi: gömülü
  `assets/app.config` içindeki `legacyLaunchpadUrl` artık fragment'sız;
  APK'nın hiçbir dosyasında eski tenant (`188b143btrial`) referansı yok.
- **Fiziksel Xiaomi doğrulaması PASSED**: Work Zone ana sayfası açılıyor,
  Better Than Bet / BTB Toto / Super Log deep link'leri çalışıyor, "Illegal
  new hash" hatası yok, eski tenant yönlendirmesi/referansı yok, normal
  Mobile Next navigasyonu ve bildirim akışı sağlıklı kalmaya devam ediyor.
