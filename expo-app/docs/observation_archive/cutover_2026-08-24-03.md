## Implementation evidence

### NXT-OBS-123 — Scout

- `LIVE`, `FIXTURE`, `SCOUT`, and the existing `STAR` filter remain native
  sibling pager pages. The first three are presented as one compact segment;
  the independent star dropdown remains available and unchanged.
- The binocular control uses checkbox semantics, a 36 dp visible control with
  hit slop, a filled active state and a separate check mark. Its press stops
  propagation, so it does not open match detail.
- Scout selection is stored as a small sorted set under a versioned local key.
  Malformed, duplicate and empty entries are rejected; the set is reconciled
  only after a successful feed and retains only matches still eligible for the
  current Live or Fixture surface. It creates no history and performs no
  BFF/SAP write.
- Emulator smoke selected one real live match, changed the Scout counter from
  `0` to `1`, displayed the non-colour-only active check and showed only that
  match on the Scout page.

### NXT-OBS-124 — result affordance

- The chevron is decorative and accessibility-hidden. It has no nested press
  handler and appears only when `currentMatchKey` exists.
- The existing full outcome cell keeps its button role, 44–48 dp target,
  pressed feedback, accessibility hint and `openCurrentMatch` action.
- Emulator smoke showed the chevron without changing score/profit alignment;
  pressing the band still opened `Maç Detayı`.

### NXT-OBS-125 — Jinx motion

- One tested motion resolver owns `AMBIENT`, `MENU`, `DRAGGING`, `GUIDING`, and
  `SUSPENDED` states. Idle never competes with menu, drag, tutorial, discovery,
  background state or reduced-motion.
- A single native-driver breathing phase controls sub-2 px hover, subtle
  asymmetric tilt/scale and the teal sparkle. Existing open/half/closed Jinx
  frames provide irregular blink, double-blink, look, bob and wink beats; the
  same beat never repeats immediately and the rest window is jittered.
- Drag start has anticipation scale and directional tilt; release uses a small
  overshoot/settle. Menu, guide and discovery keep their bounded reactions.
- The loop stops when the app is not active or Jinx is not ambient. Reduced
  motion disables continuous transforms while leaving the character and
  interaction semantics intact.
- Three 1.2-second-spaced emulator captures measured `3981` and `3186` changed
  samples inside the Jinx-only crop, confirming that the idle is not static.
  Menu expression, drag out/back and release settle completed without a fatal
  or React error.
